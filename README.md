## 2. To-Do List

# To-Do List

Приложение для управления задачами: добавление, редактирование, удаление и фильтрация задач с сохранением в localStorage.

## Стек

- HTML
- CSS
- JS

## Возможности

- Добавление задач
- Редактирование и удаление
- Отметка выполненных
- Фильтрация: все / активные / выполненные
- Сохранение в localStorage
- Счётчик оставшихся задач

## Что реализовано

- Компонентная архитектура: список, элемент, форма, фильтры
- Сохранение и восстановление состояния из localStorage
- Валидация пустого ввода
